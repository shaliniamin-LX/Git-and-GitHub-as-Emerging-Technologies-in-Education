# Git and GitHub: The Evolution of Collaborative Work
A presentation created for the MAET Emerging Technologies course, exploring Git and GitHub, how they emerged, how they work, their applications, and their broader implications through McLuhan’s Tetrad Framework.

## Contents
- **Presentation:** Git and GitHub – The Evolution of Collaborative Work
- **Videos:** Selected videos for further learning about Git and GitHub
- **References:** Sources used for research and analysis

## About
This presentation explores Git as a distributed version control system and GitHub as a platform for sharing and collaboration. It considers how these technologies have changed the way digital work is developed, documented, reviewed, and collaboratively built.

The presentation uses **McLuhan’s Tetrad Framework** to examine what Git and GitHub enhance, make obsolete, retrieve, and reverse when pushed to extremes.
